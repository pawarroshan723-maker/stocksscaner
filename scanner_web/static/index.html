A QUICK GUIDE

Read the workspace

1. Snapshot, not a live quote

Prices are stored candle closes. The latest candle can be unfinished, and provider or cached data may be stale. Check its candle date and scan time.

2. Two conditional entries

A bullish breakout requires a completed candle to close above the nearest resistance. A bullish pullback requires a touch of support and a close back above it in the same candle. Bearish conditions are mirrored.

3. Reference is not a fill

Use a full candle starting after the scan time. These price-only rules are not monitored; a later scan replaces the levels. A fill may differ or never occur. Recalculate the stop, targets and R:R for any actual fill.

Connect and import

Configure the existing local Upstox token or UPSTOX_ACCESS_TOKEN environment variable to scan. Existing master_scanner.db snapshots can be imported without changing the original file.
